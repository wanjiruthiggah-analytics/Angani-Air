# Angani Air Customer Loyalty Analysis

## Project Overview

This project analyses Angani Air’s customer loyalty programme and evaluates the impact of the 2018 promotional campaign. The analysis focuses on whether the campaign attracted customers who became active and repeat travellers.

The project was developed in Power BI using customer loyalty history, flight activity, and calendar data.

## Motivation

The campaign generated new loyalty members, but signups alone do not show whether it was successful. Angani Air needs to know whether these new members booked flights, returned to fly again, and created long-term customer value.

This project was created to turn customer and flight data into clear insights that can support campaign evaluation, customer retention, and future loyalty decisions.

## Business Question

Did the 2018 promotion attract customers who became active and repeat Angani Air travellers?

## Approach

1. Reviewed the available loyalty and flight activity data.
2. Cleaned the dataset and corrected column data types.
3. Created a calendar table and established relationships between the tables.
4. Built DAX measures to calculate signups, activation, repeat activity, bookings, loyalty tiers, and customer value.
5. Designed a three-page Power BI dashboard:
   - **Executive Overview:** Summarises overall programme performance.
   - **Campaign Analysis:** Tracks the customer journey from signup to repeat activity.
   - **Customer Analysis:** Identifies valuable inactive customers and retention opportunities.
6. Added a year slicer and page navigation to make the dashboard easier to use.

## Key Findings

- The 2018 promotion added **971 members**.
- Promotion members represented **32.3% of new members**.
- **95.0%** booked a flight within six months.
- **91.8%** became repeat flyers.
- A group of high-value inactive customers was identified as a retention opportunity.

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- Customer loyalty and flight activity datasets

## Future Improvements

- Add more years to compare campaign performance over time.
- Include points redemption and rewards engagement analysis.
- Track longer-term retention beyond six months.
- Add cancellation and churn analysis.
- Create customer segments using location, salary, loyalty tier, and flight behaviour.
- Connect the dashboard to refreshed data for regular reporting.
- Test whether targeted offers improve repeat bookings among inactive members.

## Conclusion

The 2018 promotion attracted a strong base of active and repeat customers. However, the presence of high-value inactive members shows that Angani Air should continue investing in targeted retention and loyalty strategies.
